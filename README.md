# gLab Physics — Production PWA

## Included
- Responsive polished interface
- Installable PWA manifest
- Service worker
- App icons
- Excel/CSV import
- Editable measurements
- T = t average / 20
- T² vs l scatter plot
- Best-fit line, gradient, intercept, R² and g
- CSV export
- JSON experiment backup
- Mobile-friendly installation button

## Publish
Upload the contents of this folder to an HTTPS static host (GitHub Pages, Netlify, Cloudflare Pages, etc.). Open the HTTPS URL in a supported browser and use **Install gLab**.

## Note
Chart.js and SheetJS are still loaded from jsDelivr in this build. A fully offline build should vendor those two libraries locally.
